# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

Development continues on the next release.

## [0.5.0-beta] - 2026-08-25

### Added

* Fuzzy search for quickly finding recent items within each tab.
* Double-click interaction for opening items with the default system handler.
* `Copy Path` functionality for copying the full path of an item.
* `Open With` menu for selecting applications to open items.
* Support for recent files, folders, and workspaces from VS Code-based editors.
* Support for multiple VS Code variants, including Code - OSS and VSCodium.
* KDE/XBEL recent items integration.
* Automatic discovery of VS Code database locations.
* Persistent application configuration through `apps.json`.

### Improved

* Improved interaction with recent items.
* Improved organization and presentation of recent files and directories.
* Improved VS Code integration and recent-item handling.

### Documentation

* Expanded project documentation.
* Added feature documentation to the README.
* Added development and implementation documentation.

### Notes

This is an early beta release. Features and behaviour may still change before the first stable release.

## [0.1.0] - 2026-08-06

### Added

* Initial public development release.
* KDE Plasma plasmoid for tracking recent files and directories.
* Recent items from KDE/XBEL history.
* Recent files, folders, and workspaces from VS Code-based editors.
* VS Code database discovery with support for multiple VS Code variants.
* Default system handler for opening items.
* `Open With` menu with configurable applications.
* Persistent `apps.json` configuration.
* Initial configuration and development documentation.

### Documentation

* Added project README.
* Added contribution guidelines.
* Added GPL-3.0 license.
* Added implementation roadmap and development documentation.
